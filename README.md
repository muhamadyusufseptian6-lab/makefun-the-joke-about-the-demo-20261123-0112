A small Node 22 program (stdlib only, deterministic, no network) that writes a
one-line joke about working beside an AI coding agent to `/output/entry.txt`.

## Run

```sh
node main.ts
```

The joke is written to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
It is a single line, well within the 280-character limit.
